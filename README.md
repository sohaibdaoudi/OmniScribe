# OmniScribe MVP Desktop (PyQt)

This repository contains a complete Phase 0 MVP desktop application built with PyQt.

It implements exactly the required flow:

1. Upload audio
2. Groq Whisper transcription (raw transcript)
3. Groq Llama 4 Scout Instruct correction (corrected transcript)
4. Persist both transcripts + audio metadata in PostgreSQL
5. Upload and store documents (PDF/TXT/DOCX/etc.)
6. Generate notes from corrected transcript (exact or reformulated)
7. Ask questions in chat using RAG over corrected transcripts + uploaded documents

## Stack

- UI: PyQt6
- Database: PostgreSQL + SQLAlchemy
- Transcription: Groq API (`whisper-large-v3`)
- LLM (correction, notes, chat): Groq API (`meta-llama/llama-4-scout-17b-16e-instruct`)
- Retrieval embeddings: local hashed vectors (no additional API key needed)

## Project Structure

- `app/main.py` - app bootstrap
- `app/config.py` - environment configuration and storage paths
- `app/database.py` - SQLAlchemy engine/session/init
- `app/models.py` - PostgreSQL schema models
- `app/services/ai_clients.py` - Groq API integration + local embedding helper
- `app/services/transcription_service.py` - audio -> raw + corrected transcripts
- `app/services/document_service.py` - document text extraction + persistence
- `app/services/notes_service.py` - notes generation + persistence
- `app/services/rag_service.py` - chunking, embedding retrieval, grounded answers
- `app/ui/main_window.py` - PyQt desktop interface
- `app/ui/workers.py` - background worker threads for long API jobs
- `scripts/init_db.sql` - SQL initialization script
- `.env.example` - required environment variables
- `pyproject.toml` - project metadata and dependencies managed by uv
- `uv.lock` - locked dependency graph generated by uv
- `run.py` - run entrypoint

## PostgreSQL Schema (MVP)

The app persists:

- `audios`: audio metadata and storage path
- `transcripts`: raw and corrected transcript for each audio
- `documents`: uploaded document metadata + extracted text
- `notes`: generated notes by mode (`exact` or `reformulated`)

Schema SQL is in `scripts/init_db.sql`.

## Setup

### 1. Install uv (if not already installed)

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 2. Create virtual environment and install dependencies

```bash
uv sync
```

`uv sync` creates/updates `.venv` and installs exactly what is pinned in `pyproject.toml` + `uv.lock`.

### 3. Add or update dependencies

```bash
uv add <package>
```

For exact version pins, use:

```bash
uv add "package==x.y.z"
```

### 4. Configure environment variables

```bash
cp .env.example .env
```

Fill in your API keys in `.env`:

- `GROQ_API_KEY`

Optional alias also supported:

- `QROP_API_KEY`

Model overrides (optional):

- `GROQ_WHISPER_MODEL` (default: `whisper-large-v3`)
- `GROQ_CHAT_MODEL` (default: `meta-llama/llama-4-scout-17b-16e-instruct`)

### 5. Prepare PostgreSQL database

Create database:

```bash
createdb omniscribe
```

Initialize schema (optional, app can also auto-create tables via SQLAlchemy):

```bash
psql -d omniscribe -f scripts/init_db.sql
```

### 6. Run desktop app

```bash
uv run omniscribe
```

Alternative launch commands from project root:

```bash
uv run python run.py
uv run python -m app.main
```

## MVP User Flow

1. Open `Audio & Transcripts` tab
2. Select audio file, provide title, click `Upload + Transcribe`
3. App stores:
   - raw transcript (Groq)
   - corrected transcript (Groq Llama 4 Scout Instruct)
4. Open `Documents` tab and upload PDF/TXT/DOCX files
5. Open `Notes` tab:
   - choose `Exact teacher wording` or `Reformulated version`
   - click `Generate Notes`
6. Open `AI Chat` tab and ask questions
   - answers are grounded on corrected transcripts + documents

## Notes

- Long API operations run in background worker threads, so the UI remains responsive.
- RAG is intentionally simple for MVP: chunk text, embed locally with hash vectors, cosine rank, then answer with Groq using retrieved context.
- No advanced features are added beyond Phase 0 scope.
