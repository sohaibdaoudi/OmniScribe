Supervised learning involves learning a mapping from inputs x to outputs y, given a training dataset of (x, y) pairs. The goal is to minimize a loss function L(ŷ, y) that measures the discrepancy between predicted and actual outputs. Common loss functions include: • MSE for regression: L = (1/n) Σ (ŷᵢ − yᵢ)² • Cross-entropy for classification: L = −Σ yᵢ log(ŷᵢ) Gradient descent updates weights θ via: θ ← θ − α ∇L(θ)

Gradient Descent
Algorithm for minimizing the loss function by iteratively updating model weights in the direction of the negative gradient.
Update rule: θ ← θ − α ∇L(θ), where α is the learning rate.
"Think of it as walking down a hill blindfolded — you just keep going downhill until you hit the bottom."
Loss Functions
MSE (Mean Squared Error) — used for regression tasks.
Cross-entropy loss — used for classification, penalizes confident wrong predictions heavily.
Key Concepts to Review
Backpropagation — chain rule applied to compute gradients through layers.
Vanishing gradient problem — small gradients in early layers slow learning.
Learning rate schedule — adaptive methods like Adam, RMSProp.
